**R-26 多行粘贴保护 / 危险命令确认（桌面端闭环）**：

- 新增 `command_check` IPC，调用 Rust 分类器并以稳定 camelCase DTO 返回结果；纯本机检查，不保存或上传输入，单次最多 1 MiB 文本。
- 所有桌面终端窗格在粘贴前检查完整文本与已输入前缀；多行或危险模式显示目标终端、原因与内容预览。危险输入按钮为「仍然发送」，其他提示为「确认发送」；取消不补发。保留 xterm 的 bracketed paste，不自动追加回车。
- 手工输入回车前检查当前编辑行；修改已确认内容后重新检查。历史记录、Tab 补全或无法完整追踪的编辑，除检查可见行外额外要求用户核对，避免远端输出未到达时漏过确认。检查/确认期间阻止后续输入越过待确认内容；待确认输入不会排队补发。
- 确认界面在会话结束、面板卸载时取消，异步返回不能把旧输入发送到新会话；检查失败停止本次发送并提示，取消/确认后恢复当前终端焦点。
- 补齐绝对路径/带引号可执行文件与参数、混合 `rm -rI` 参数、无空格分号、命令/进程替换、shell `-c`、Git 非相邻强制参数、CRLF、反斜杠/引号续行、常用 PowerShell/CMD 破坏性操作识别；保留安全文字示例和注释，`/dev/null` 常规重定向不再误报。
- 分类是启发式提醒，不能解析完整 shell、别名、动态变量和远端程序状态；不作为权限隔离或任意脚本安全保证。协议字节、终端响应和已单独授权的插件自动化保持各自输入路径。本项验证范围为桌面端。


**R-24 应用级命令面板 / 历史命令搜索 + R-38 按主机命令历史隔离检索（核心逻辑层）**：

- 新增 `crates/term-core/src/history.rs`：纯函数 `search_history`（匹配 / 排序 / 按主机隔离）+ `matches_query`（字面子串匹配）。
- 排序分数：完全相等(100) > 前缀匹配(70) > 词边界匹配(50) > 子串匹配(30)；同分按 使用次数 → 最近使用 → 命令字典序 稳定排序。
- 主机隔离（`R-38`）：`host_filter = Some(id)` 仅返回该主机命令 + 本地命令（`host_id` 为 None），严格不把主机 A 的历史泄露到主机 B；`None` 为全局检索。
- 字面匹配：查询按字面子串匹配（默认大小写不敏感），正则元字符（`.` `*` `(` 等）按字面处理，避免误报与 panic（P4）。
- 聚合去重：相同命令（大小写不敏感）同主机合并为一条，累加 `use_count`、取最新 `timestamp`；区分大小写模式下保留原大小写。
- `storage.rs` 新增本地 `command_history` 表（不参与 LWW 同步 / 备份，避免污染跨设备同步）及 `history_add` / `history_list` / `history_search` / `history_clear`；`history_search` 委托纯函数完成检索。
- **27 项 P0–P5 单测**（history.rs 22 + storage.rs 5）：P0 正常路径 / P1 核心匹配与排序 / P2 边界（空列表、无匹配、单行、空白查询、max_results=0） / P3 组合与按主机隔离（A 专属命令不泄露到 B、同机去重、大小写不敏感去重、不同主机不合并） / P4 防误报（正则元字符字面、特殊字符、Unicode、区分大小写） / P5 极端回归（5000 条性能与聚合、超长命令、100 主机隔离、CRLF）。
- `lib.rs` 导出 `HistoryEntry` / `HistoryQuery` / `search_history` / `matches_query`。

## 构建与验收限制

- macOS Apple Silicon：本机 release app/DMG 构建；应用使用 ad-hoc 签名，未 Apple 公证。产物位于仓库根 `target/release/bundle`。
- Linux ARM64（2026-10-24 历史证据，本次插件/应用拆分未重新构建）：Debian 12 容器 release 构建 DEB/RPM/AppImage、56 项 Rust 与 14 项前端测试通过；DEB 实际安装，DEB/AppImage 在独立数据目录的 Xvfb 图形环境下分别持续存活 12/15 秒并创建数据库。容器以 root 运行时仅对测试进程设置 WebKit sandbox 环境变量，不作为用户安装建议；容器验证不等于所有 Linux 桌面实机验证。
- **尚未完成的验收证据**：零插件冷启动/RSS 与无插件基线 ≤5% 的严格量测、四分屏内存预算、Windows 实机/安装包回归、Linux x64/Wayland/多桌面、真实 AI 服务/Key、真实远端 Zmodem/Sixel 互通、真实外部网络弱网/转发/串口硬件。以上不能用编译或协议回环结果替代。
- 自托管 registry 客户端已实现，未部署公共市场服务；没有虚构公共下载地址。内置插件版本随应用交付。
- SFTP 重试会重新传整个文件；失败上传可能留下远端 `.part`，原目标不会被半文件覆盖。日志读取上限 8 MiB、列表上限 500。
- Linux Secret Service 需要桌面 keyring 服务；无该服务的 headless 容器只验证无凭据启动，不代表密钥环成功。

此前文档中的 Windows SAC 构建限制属于历史环境；当前 macOS / Linux 构建证据已单列，不再沿用“后端未编译”的过时结论。
